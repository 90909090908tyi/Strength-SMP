# StrengthSMP

Paper plugin for Minecraft 1.21.11, built with Java 21.

## Build

Run `gradle build`. The plugin JAR is generated at `build/libs/StrengthSMP-1.0.0.jar`.

The minimum strength defaults to `0` and can be changed in `plugins/StrengthSMP/config.yml`.

## Commands

Player commands: `/strength`, `/bind`, `/withdraw`, `/bounty`, `/ability`, and `/removeprotection`.

Admin commands require `strengthsmp.admin`: `/strengthsmp reload`, `setstrength`, `setweapon`, `reroll`, `giveitem`, `maintenance`, and `resetplayer`.
